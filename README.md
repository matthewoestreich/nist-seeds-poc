# ECDSA Origins

[As you've most likely heard, Claude solved the mystery of the ECDSA curve origins](https://www.anthropic.com/research/ecdsa-curve-origins). This proof of concept demonstrates how those curves may have been generated by reconstructing their seeds using `drand48` and the suspected generation timestamps.

# Usage

Install dependencies:

```bash
$ npm install
```

If you are running `Node v22.18.0` or above you can do: `node src/main.ts`.

Otherwise, you'll need to run the transpiled `main.js` file after building.

```bash
$ npm run build
$ node dist/main.js
```
